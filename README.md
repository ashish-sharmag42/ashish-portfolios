## Preview locally

Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload **the contents of this folder** (not only the ZIP).
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

## Personalization notes

Before publishing, review:
- Exact job titles and dates in the Career Journey section
- Exact certifications/credential names
- The third recommendation, which is intentionally marked as a placeholder summary
- Any quantified business outcomes you want to add

The visual layout does not depend on these values, so they can be edited directly in `index.html`.
